# Analytic Geometry

Deck 03 of the [Mathematics for Machine Learning &mdash; Companion Series](https://github.com/BrendanJamesLynskey/MML_Hub).

**Live presentation:** https://brendanjameslynskey.github.io/MML_03_Analytic_Geometry/

Norms, inner products, lengths &amp; distances, angles, orthonormal bases,
orthogonal complements, orthogonal projections, rotations. The geometry
that turns "least squares" in deck 09 into "drop a perpendicular".

## What's inside

- Norms, the unit-ball picture, and which norm to choose
- Inner products and the abstract definition that lets us put one on function spaces
- Lengths, distances, angles, Cauchy&ndash;Schwarz
- Orthonormal bases and the Gram-Schmidt procedure
- Orthogonal complement and the four-subspace orthogonality of deck 02
- Orthogonal projection onto a subspace (interactive 2D demo)
- Rotations in $\mathbb{R}^2$ and $\mathbb{R}^3$
- How projection underpins linear regression, PCA, GMM and the SVM
